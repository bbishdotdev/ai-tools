# ai-tools

My collection of skills, agents, and tools for working with AI coding assistants. Each tool lives in its own folder with its documentation and installation instructions.

## Available tools

| Tool | What it does | Get started |
| --- | --- | --- |
| [bstack](bstack/README.md) | An opinionated suite connecting planning, engineering, local work tracking, and optional shared memory across coding assistants. | [Install bstack](bstack/INSTALL.md) |

Shared memory and PR workflows currently ship as part of bstack.

## Updates

Each tool keeps its changelog and release guidance in its own folder. See [bstack's changelog](bstack/CHANGELOG.md) for published and unreleased changes, and [its release guide](bstack/RELEASING.md) for versioning and packaging.
