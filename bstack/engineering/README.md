# Engineering

This directory contains bstack-owned engineering workflows. [Prototype](prototype/WORKFLOW.md) is the first approved workflow here. Its [design notes](prototype/REVIEW.md) describe the structure and completed instruction review. It will join active routing after the shared handoff and session contract is in place.

The current consumer release uses the [bstack router](../shared/skills/bstack-router/SKILL.md) with selected pinned engineering dependencies. Browse the [PStack skill catalog](../audit/catalog.md) or the [source skills](../upstream/pstack/skills/). Those source snapshots live under [upstream](../upstream/README.md). Keep custom workflows here and source snapshots there so each can evolve without overwriting the other.

See [SDLC integration](../sdlc/integration-review.md) for how planning and engineering connect, and [central attribution](../../ATTRIBUTION.md) for source relationships and notices.
