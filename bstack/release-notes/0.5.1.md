# bstack 0.5.1

Find bstack's setup, release history, and source credits together, with a shorter ai-tools overview at the repository root.

## Changes

### Changed

- The root README introduces the ai-tools collection. bstack's overview, credits, installation, usage, and maintainer guidance now live together in `bstack/README.md`.
- bstack's attribution and changelog moved into its folder. Documentation, skill references, and package source records follow the new paths.
- Installed skill paths, workflow instructions, runtime code, and complete third-party notices are preserved.

## Upgrade

No data migration or new settings are required. Use the new installer in your existing project, then start a fresh agent session. The upgrade from 0.5.0 preserves saved workspace data, ADRs, project instructions, selected tools, and automatic-routing preferences. Shared memory setup remains optional.

## Install

Download **bstack-0.5.1.zip** and **SHA256SUMS** from this release. Extract the ZIP and ask your agent to read its `SKILL.md` and install into your project, or run from the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same installer to upgrade. Requires Python 3.11+ on macOS or Linux. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.5.1/bstack/INSTALL.md) for skills.sh and other options.
