# bstack 0.5.0

Carry important architecture decisions through planning and engineering without turning every feature into a pile of documentation.

## Changes

### Added

- One shared ADR process across planning, research, implementation, and handoffs. Agents consult relevant decisions, reuse settled reasoning, and explain changed circumstances before proposing a reversal. Most features need no ADR.
- A read-only ADR catalog that lists decision metadata and checks duplicate IDs, broken replacement links, and inconsistent supersession. It works without initializing a workspace.
- A changelog, release-note template, and release guide covering version selection and the difference between a main-branch update and a published release.

### Changed

- New projects default to short, numbered ADR files in a flat `docs/adr/` folder, with private drafts. Existing document locations and formats stay in place.
- The README explains bstack's custom workflows and its reuse of, adaptations to, and inspiration from Lauren "poteto" Tan's PStack and Matt Pocock's skills.

## Upgrade

No data migration or new settings are required. Run the new installer in your existing project, then start a fresh agent session. Upgrades preserve selected tools and automatic-routing preferences. Existing ADRs are not moved or rewritten, and shared personal memory remains a separate, optional setup.

## Verification

- 135 automated checks passed on Linux with Python 3.14, covering package assembly, installation, transport, ADR handling, and existing workflow configuration.
- Independent review and fresh-agent exercises checked the ADR threshold, reuse of accepted decisions, proposed reversals, and installed skill references.
- Fresh installation and an upgrade from 0.4.2 were checked using the release ZIP, including package integrity, saved workspace data, selected tools, and automatic-routing settings.

The catalog checks document structure, not the truth of a decision or its approval. Editing a linked ADR does not automatically invalidate approved specs or tickets; agents must reread and reconcile affected work. This release does not claim new desktop or cross-provider model verification.

## Install

Download **bstack-0.5.0.zip** and **SHA256SUMS** from this release. Extract the ZIP and ask your agent to read its `SKILL.md` and install into your project, or run from the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same installer to upgrade. Requires Python 3.11+ on macOS or Linux. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.5.0/bstack/INSTALL.md) for skills.sh and other options.
