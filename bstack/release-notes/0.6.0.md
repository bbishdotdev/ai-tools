# bstack 0.6.0

Give every project the same concise starting rules for agent behavior, without replacing its existing guidance.

## Changes

### Added

- Setup installs seven baseline rules for respecting scope, challenging weak reasoning, communicating naturally, weighing implementation approaches, fixing root causes, writing meaningful tests, and keeping code readable without comments.
- The source is `shared/references/baseline-agents.md`. Setup writes the rules directly into a managed block in `AGENTS.md` and, when Claude is selected, `CLAUDE.md`. Missing files are created. Shared symlinks keep one copy.
- The baseline applies with automatic routing off and takes precedence over conflicting imported workflow guidance.

### Changed

- Updates preserve project text around the managed block. `doctor` detects changed or missing blocks, and setup refuses to overwrite them. Uninstall removes the owned block while keeping project guidance.
- Native tool initialization remains optional. Setup does not run `/init`; add project-specific guidance outside the managed block and run `doctor` after using a tool's initializer.

## Upgrade

Run the new installer in your existing project, then start a fresh agent session. Existing installations gain the baseline automatically. No new settings or data migration are required. The upgrade from 0.5.1 preserves selected tools and automatic-routing preferences.

If setup reports a changed managed block, reconcile it before retrying. Keep project-specific instructions outside the block. See [project instructions](https://github.com/bbishdotdev/ai-tools/blob/v0.6.0/bstack/INSTALL.md#project-instructions).

## Verification

- Three new installer lifecycle tests cover upgrades from older packages, fresh clones with legacy instruction blocks, and detection of blocks replaced by initialization. Existing lifecycle coverage also checks preservation, repeat setup, and uninstall.
- Package, installer, transport, layer, and shared workflow checks passed on Linux. The release ZIP passed fresh installation and an upgrade from 0.5.1, including retained tool selections and automatic routing.

These checks verify installed files and installer behavior. They do not establish that every model follows every rule or that native tool initializers preserve the block.

## Install

Download **bstack-0.6.0.zip** and **SHA256SUMS** from this release. Extract the ZIP and ask your agent to read its `SKILL.md` and install into your project, or run from the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same installer to upgrade. Requires Python 3.11+ on macOS or Linux. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.6.0/bstack/INSTALL.md) for skills.sh and other options.
