# bstack 0.8.1

Prepared draft. This version was not tagged or published; its changes are included in 1.0.0.

The setup and upgrade paths now explain what gets installed, when to start a fresh session, and how to choose a workflow without following a fixed SDLC sequence.

## Changes

- The README maps common jobs to their entry skills and explains how the package loads instructions on demand.
- The install guide separates skills.sh, release ZIP, and clone setup, and spells out the two-step upgrade: refresh the installer, then run it for each project.
- The packaged README carries the same workflow and upgrade guidance. The release-directory quick start now uses the bundled installer, which runs `doctor` after setup.
- Older verification reports are labeled as dated evidence. The release manifest remains the current skill inventory.

## Upgrade

No migration is required. Run the newer installer against each project and follow its fresh-session notice. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.8.1/bstack/INSTALL.md) for skills.sh and offline routes.

## Verification

Package build/check and 89 package/runtime tests passed. The offline installation verifier passed, and a fresh project installed from the 0.8.1 ZIP with 45 public skills, all four host bindings, the PR template, and a passing `doctor`. Local Markdown links and the ZIP checksum also passed. CLI model behavior and desktop discovery were not rerun.

## Install

Download **bstack-0.8.1.zip** and **SHA256SUMS** from this release. Extract the ZIP and ask your agent to read its `SKILL.md` and install into your project, or run from the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same installer to upgrade. Requires Python 3.11+ on macOS or Linux. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.8.1/bstack/INSTALL.md) for skills.sh and other options.
