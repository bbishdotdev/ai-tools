# bstack 0.8.0

Handle PR feedback without turning every suggestion into code, and get safer upgrades and clearer PRs.

## Changes

### Added

- `resolve-pr` checks reviewer claims against the code, accepted ADRs, and the PR's purpose. It supports a scoped fix, an evidence-backed reply with no code change, or a separate follow-up. Its GitHub helper previews replies, checks that the discussion is still current, and avoids duplicate posts after an uncertain result. It does not clear another person's request-changes review.
- Setup adds a starter PR template when a project has none. It reports existing templates without overwriting them; project edits to the starter stay project-owned.

### Changed

- `review-pr` rechecks a PR that changes during review and limits itself to three passes. `to-pr` and `review-pr` now share standards for purpose, scope, evidence, decisions, and risk.
- `to-pr` requires a real image or diagram for non-micro changes. Uploaded images include a Mermaid fallback.

### Fixed

- Upgrades can recreate a missing BStack-managed block in `AGENTS.md` or `CLAUDE.md`. They warn when other project instructions in a missing file cannot be recovered, and still stop if an existing managed block has changed.

## Upgrade

Rerun the installer in each project, then start a new agent session to load the updated skills. Existing selected tools and automatic-routing settings remain in place. Review any warning about a missing root instruction file; BStack cannot restore project text that was outside its managed block. No saved-data migration is required. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.8.0/bstack/INSTALL.md).

`resolve-pr` needs an authenticated GitHub CLI to capture and post GitHub feedback. A reply-only resolution needs no local checkout, but a code fix needs a pushed, checked commit before replying.

## Verification

- Package, layer, runtime, transport, shared workflow, and GitHub helper checks passed on Linux.
- The release ZIP passed checksum verification and a disposable installation with `doctor`.
- The `resolve-pr` helper was tested locally for stale feedback and retry behavior. This release did not post a live GitHub reply through that helper.

## Install

Download **bstack-0.8.0.zip** and **SHA256SUMS** from this release. Extract the ZIP and ask your agent to read its `SKILL.md` and install bstack into your project, or run from the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same installer to upgrade. Requires Python 3.11+ on macOS or Linux. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.8.0/bstack/INSTALL.md) for skills.sh and other options.
