# bstack 0.4.2

Download and install the complete bstack collection without cloning the repository or using skills.sh.

- A versioned ZIP includes the skills, pinned dependencies, workspace app, and installer.
- Installation verifies the package, preserves existing tool and routing settings on upgrades, and explains when to start a fresh agent chat.
- Agents can select `install-bstack` for setup requests and offer automatic routing after verification. Automatic routing stays off until you opt in.
- Atlas shows a clearer dependency map with readable cards, selection focus, and controls for larger maps.

## Install

Download **bstack-0.4.2.zip** from this release and extract it. Ask your agent to install bstack from the extracted folder into your project, or run this inside the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same command to upgrade an existing installation. The extracted README explains tool selection and optional setup.

Requires Python 3.11 or newer on macOS or Linux. Installation uses the bundled files and needs no network access. Agent tools must already be installed separately. Shared memory remains an optional setup step.

Download **SHA256SUMS** alongside the ZIP to verify the archive before extracting it.
