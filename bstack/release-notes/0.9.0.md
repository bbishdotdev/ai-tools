# bstack 0.9.0

Bstack now has a short guide that helps people find the right starting point without turning on an engineering workflow.

## Changes

- Added `bstack-guide`. Ask how to use bstack, invoke the skill directly, or request a walkthrough during setup. It explains manual and automatic routing, common planning and engineering paths, the local workspace, PR work, and optional memory. Its offline HTML page adds a full searchable catalog, Cmd/Ctrl+K palette, and a clear comparison of manual, Poteto, and auto routing.
- Setup recommends the guide after a healthy install. It can give the walkthrough in the same session when the user requests it, or direct the user to a fresh session when the skill catalog needs to reload.
- Corrected the docs for `bro`: it restates the last answer plainly; `poteto-mode` selects an engineering workflow.

## Upgrade

Run a 0.9.0 installer over the existing project. The selected hosts and automatic routing preference remain project settings. Start a fresh agent session when the installer requests it, then ask how to use bstack or invoke `bstack-guide`.

## Verification

The guide passed the skill validator. Source-layer, package, runtime, transport, shared, and GitHub checks passed (208 tests total); package integrity checked 278 files. A fresh offline install and an upgrade from 0.8.1 passed `doctor`, kept all four host bindings, and preserved automatic routing. The HTML page passed catalog-coverage, link, offline-asset, and JavaScript syntax checks. Visual browser rendering and live model selection in desktop apps were not tested.

## Install

Download **bstack-0.9.0.zip** and **SHA256SUMS** from this release. Extract the ZIP and ask your agent to read its `SKILL.md` and install into your project, or run from the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same installer to upgrade. Requires Python 3.11+ on macOS or Linux. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.9.0/bstack/INSTALL.md) for skills.sh and other options.
