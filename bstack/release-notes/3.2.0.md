# bstack 3.2.0

bstack now has measured desktop support: Claude Code desktop, Cursor desktop, and VS Code with Copilot pass every scenario, and your own project verifiers can drive desktop apps the same way.

## Changes

### Added

- A computer-use kit for `create-verification-skill`. When a user path runs through a desktop app, editor panel, or interactive terminal that no headless driver reaches, a project verifier can hand it to a computer-use agent: a harness, a shared probe set, one script per surface, a handoff, and a report template, all graded by code. It includes an evidence helper with a focus check so the agent doesn't type into the wrong window. See the [kit](https://github.com/bbishdotdev/ai-tools/blob/v3.2.0/bstack/engineering/create-verification-skill/computer-use/README.md).
- Desktop compatibility in the matrix. Claude Code desktop, Cursor desktop, and VS Code with Copilot are Supported in all four columns: skills, auto mode, PR workflows, and hooks. They run the same scenarios as the CLIs, with a computer-use agent at the controls through first-run trust, folder pickers, approvals, and native compaction.
- The README opens with the supported tools and whether each has CLI or CLI and desktop bindings.

### Fixed

- Copilot hooks now run in VS Code. VS Code uses its own event names and terminal tool for the Copilot binding, so the router reminder and PR guard were silently skipped there.
- The router and its reminder now say task size is no exemption: a one-line fix still opens its playbook.

## Upgrade

No special steps. Run the newer installer in the existing project, then start a fresh agent session. Existing host selections, routing mode, and verification mode are preserved. See [installation and updates](https://github.com/bbishdotdev/ai-tools/blob/v3.2.0/bstack/INSTALL.md).

## Verification

Package, layer, runtime, transport, installer, shared workflow, and GitHub-helper checks passed on Linux. Release verification includes a fresh install from the 3.2.0 ZIP and an upgrade over the published 3.1.0 ZIP.

Desktop results come from computer-use runs on Linux with one attempt per scenario; see the [compatibility results](https://github.com/bbishdotdev/ai-tools/blob/v3.2.0/bstack/audit/compatibility-results.json). In Claude Code desktop's `direct-pr` case, the guard blocked a raw `gh pr create` and Claude went on through to-pr. The published PR went to a disposable fake forge, not GitHub.

Limits: Copilot CLI's PR workflows stay Partial because its last guard probe hit the account's monthly quota. Codex desktop, OpenCode desktop, and the terminal UIs are still being exercised. Supported means the integration passed its scenarios, not that every model completes every task; model quality is tracked separately in [model results](https://github.com/bbishdotdev/ai-tools/blob/v3.2.0/bstack/audit/model-results.md).

## Install

Download **bstack-3.2.0.zip** and **SHA256SUMS** from this release, verify the checksum, and extract the ZIP. Ask your agent to read its `SKILL.md` and install into your project, or run from the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same installer to upgrade. Requires Python 3.11+ on macOS or Linux. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v3.2.0/bstack/INSTALL.md) for skills.sh and other options.
