# bstack 1.0.0

BStack now gives teams one way to find its workflows and add their own PR review priorities without changing the shared skills.

## Changes

- Added `bstack-guide` and an offline, searchable reference page for the skill catalog, common workflows, and manual versus automatic routing. Setup points new users to it after a healthy install.
- Added `configure-pr` and an optional, committed `bstack-pr-policy.md` at each repository root. Teams can name human-review paths, critical behavior, review focus, and existing Markdown standards. `to-pr`, `review-pr`, and `resolve-pr` use the same policy on top of BStack's shared PR standards.
- The `review-pr` runner reads policy from the accepted target revision. It withholds AI approval for matched human-review paths, including edits to the policy file itself. An invalid policy or missing referenced standard leaves a partial review with its findings and limits intact.
- Setup guidance now distinguishes a globally available installer from a package configured in a child Git repository. A parent BStack install alone does not provide the child's Claude skill bindings or auto hook.
- Improved installation, upgrade, and workflow documentation since 0.8.0, including fresh-session guidance for Claude Code desktop.
- `to-pr` now explicitly keeps PR-only visuals out of the repository and uploads them as PR attachments.

## Upgrade

Refresh `install-bstack` or download this release ZIP, then run the installer for each repository where you use BStack. Existing hosts and the auto-mode preference remain project settings. If BStack was installed only in a parent folder, install it in the child repo and enable auto there if you want automatic routing. Start a fresh Claude Code desktop Code chat rooted in that repo after setup.

The project PR policy is optional. No policy is copied into consuming repositories automatically. Ask `configure-pr` to create one when you have project-specific priorities.

## Install

Download **bstack-1.0.0.zip** and **SHA256SUMS** from this release. Extract the ZIP and ask your agent to read its `SKILL.md` and install into your project, or run from the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same installer to upgrade. Requires Python 3.11+ on macOS or Linux. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v1.0.0/bstack/INSTALL.md) for skills.sh and other options.
