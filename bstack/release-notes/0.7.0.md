# bstack 0.7.0

Review PRs with two independent models and a third model that challenges their findings. The PR-writing workflow can also use Codex image generation to explain a change visually when the project allows it.

## Changes

### Added

- `review-pr` checks whether a PR needs review, runs two independent reviewers, and gives their anonymous findings to a fresh adjudicator. It considers current ADRs, prior review feedback, and whether the PR is needed at all. A clean review is a valid result.
- Follow-up reviews focus on new changes and relevant replies. The publishing step can agree with earlier feedback, reply to it, or raise a distinct finding without duplicating another reviewer's requested-changes status. Incomplete assessments retain useful findings but cannot approve.

### Changed

- `to-pr` can ask Codex CLI for an explanatory image in a read-only session when that provider is allowed to see the project. The agent checks the result against the diff. If it is unavailable or unhelpful, the workflow uses the current agent's image tool or a simpler visual that explains the change.
- Review replies keep public text short and conversational while linking to the earlier discussion and reviewed commit. Detailed evidence stays in the private assessment.

## Upgrade

Rerun the new installer in each project, then start a fresh agent session so the updated skills are visible. Existing selected tools and automatic-routing settings are preserved. No saved-data migration is required. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.7.0/bstack/INSTALL.md).

`review-pr` currently needs authenticated GitHub CLI plus available Codex and Claude Code CLIs for model execution. Its model choices and publication are separate from installation. Codex image generation in `to-pr` is optional and requires the project's permission to use that provider.

## Verification

- Package, layer, transport, installer, shared workflow, and GitHub helper checks passed on Linux.
- The release ZIP passed checksum verification and a disposable installation with `doctor`.
- The PR-review workflow was exercised with Codex and Claude Code on a live draft PR, including GitHub publication. This verifies that path; it does not establish identical behavior across every host or model combination.

## Install

Download **bstack-0.7.0.zip** and **SHA256SUMS** from this release. Extract the ZIP and ask your agent to read its `SKILL.md` and install bstack into your project, or run from the extracted folder:

```sh
python3 install.py --project /path/to/my-project
```

Use the same installer to upgrade. Requires Python 3.11+ on macOS or Linux. See [installation](https://github.com/bbishdotdev/ai-tools/blob/v0.7.0/bstack/INSTALL.md) for skills.sh and other options.
