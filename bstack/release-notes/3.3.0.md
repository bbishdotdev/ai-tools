# bstack 3.3.0

When an agent prepares a pull request through `to-pr`, BStack can now sign the PR with the model that prepared it, even if the agent omits the model flag.

## Changes

- BStack reads the host metadata for the specific PR preparation call. The footer identifies the response model when available and labels a host-selected model when that is the evidence the tool provides. The signature stays with the prepared PR if another agent publishes it later. [PR #29](https://github.com/bbishdotdev/ai-tools/pull/29)
- Agents can still supply an exact ID with `--author-model` when the hook has no model to report. If both sources supply an ID and they disagree, preparation stops. If neither supplies one, the footer reads `Model attribution unavailable`.
- The PR verification harness now checks that each simulated PR has a matching creation command and a pushed branch. Writing a PR directly into the test data can no longer produce a pass. [PR #28](https://github.com/bbishdotdev/ai-tools/pull/28)

## Install or upgrade

Download **bstack-3.3.0.zip** and **SHA256SUMS**, verify the checksum, and extract the ZIP. From the extracted `bstack` folder, run the installer against your project with Python 3.11 or later on macOS or Linux.

```sh
python3 install.py --project /path/to/my-project
```

Run the same command for an upgrade, then start a fresh agent session. The installer preserves your selected tools, routing mode, and verification preference. [Installation guide](https://github.com/bbishdotdev/ai-tools/blob/v3.3.0/bstack/INSTALL.md)
