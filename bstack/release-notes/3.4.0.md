# bstack 3.4.0

Distribute BStack as one complete installer folder, with hooks that keep using the Python interpreter selected during setup.

## Changes

- A complete release folder exposes one `bstack` installer skill and carries every required asset. Bundled instruction files avoid duplicate nested skill discovery. The existing archive installer remains available. [PR #33](https://github.com/bbishdotdev/ai-tools/pull/33)
- Setup records a working Python 3.11+ interpreter for generated commands across all seven supported hosts. Doctor checks command startup after package and binding integrity checks.
- Generated bindings stay local to each checkout. Shared ignore rules preserve visibility exceptions without invalidating another developer's installation. Claude hooks move to local settings while preserving unrelated configuration.
- Worktree cleanup holds a checkout when Git cannot determine whether it has unpushed commits. An inspection failure no longer counts as evidence that removal is safe. [PR #31](https://github.com/bbishdotdev/ai-tools/pull/31)
- Wayfinder loads kanban state only when needed and avoids rebuilding the same question views and prerequisite indexes during map reads. [PR #32](https://github.com/bbishdotdev/ai-tools/pull/32)

## Upgrade

Run setup in each developer's checkout, then start a fresh agent session. Setup keeps its own copy in `.bstack/package/`, so updating or removing the distributor's folder does not silently change the installed runtime. Rerun setup after a distributor update.

Review the shared `.gitignore` changes before committing them. Keep generated machine-specific bindings out of Git; doctor reports tracked or visible generated paths and mixed host settings that need attention. Existing host selections, automatic routing, and verification preferences are preserved during upgrade.

Doctor's command probes check startup from its shell. They do not establish native host delivery, desktop discovery, or interactive hook trust. Codex hook trust still needs the host's normal approval.

## Install

Download **bstack-3.4.0.zip** and **SHA256SUMS**, verify the checksum, and extract the ZIP. From the extracted `bstack` folder, run:

```sh
python3 install.py --project /path/to/my-project
```

Use the same command to upgrade. Requires Python 3.11+ on macOS or Linux. To distribute an extracted release through a folder-based skill installer, select its root `bstack` skill and explicitly run setup. [Installation guide](https://github.com/bbishdotdev/ai-tools/blob/v3.4.0/bstack/INSTALL.md)
